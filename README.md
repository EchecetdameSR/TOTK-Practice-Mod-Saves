# TOTK-Practice-Mod-Saves
Updated practice saves for the Tears of the Kingdom Practice Mod. Based on the Practice Mod v3.0 made by Echocolat, with fixes for accurate speedrun practice.

## Installation

1. Make sure you already have the base mod installed on your Switch.
2. Open the folder containing the base mod `romfs` directory.
3. Drag and drop the `romfs` folder from this patch into the base mod folder.
4. If prompted, allow the files to merge and **replace the existing files**.

The patch is now applied.
